🐢 Ham 1

The original Python/Turtle Ham simulation. This is where the Ham saga began.

About this project

Ham 1 is a Python Turtle pet simulation where your turtle gets hungry, sleepy, happy, levels up, plays with toys, finds food, gets zoomies, and eventually changes color as it levels up.

This original version is preserved as part of the GooseyWorks archives.

📥 Download Turtle Life 1 👀 View Python Code

🐢 Run Ham 1

The original Ham 1 was written in Python using Turtle. The old browser embed used Trinket, so this archive now provides the original Python file instead.

Download the file and run it using Python on your computer. Python's Turtle graphics opens its own window.

The archive preserves the original program rather than replacing it with a JavaScript remake.
